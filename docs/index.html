[ THE FRONT ]

Your apps know the handshake.

Use AWS CLI, rclone, or an S3 SDK. Set the endpoint and credentials. Your app doesn't need the origin story.

[ THE WAREHOUSE ]

Files. On a disk. Revolutionary.

Objects and metadata live in your data directory. No external database to recruit into the operation.

[ THE BOUNCER ]

No signature, no shipment.

SigV4 authentication, presigned URLs, and optional TLS. Sunglasses alone do not count as credentials.

Set up shop

Less ceremony.
More storage.

From the repository, build and start lc. Then point your S3 client at http://127.0.0.1:9000 with the same credentials.

This example stays on localhost. Use real secrets and configure TLS before exposing it to a network.

The honest bit

A storage server. Not the whole cloud.

Buckets, objects, listings, multipart uploads, range requests, and copy operations are on the menu. Versioning, replication, lifecycle policies, and IAM are not implemented. Keep backups. Even the boss keeps backups.
